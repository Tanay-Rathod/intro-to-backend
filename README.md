# Intro to Backend Web Development

This project is a complete Node.js, Express, and MongoDB backend application built following the freeCodeCamp tutorial by Shivani.

## Features
- **Authentication APIs**: Register, Login, Logout (with password hashing using `bcrypt`)
- **CRUD APIs for Posts**: Create Post, Read All Posts, Update Post (Patch), Delete Post
- **Architecture**: MVC Pattern (Models, Controllers, Routes, Config)

## Setup & Running
1. Extract the project.
2. Open terminal in the directory and run:
   ```bash
   npm install
   ```
3. Setup your `.env` file with your MongoDB connection string.
4. Run the dev server:
   ```bash
   npm run dev
   ```
